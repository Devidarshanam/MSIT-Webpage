# MSIT Announcement Single‑Page Website

This repository contains a clean, responsive, single‑page website for the **Master of Science in Information Technology (MSIT)** programme at IIIT Hyderabad.

## Project Structure
```
msit-announcement/
├─ index.html
├─ assets/
│   ├─ css/
│   │   └─ styles.css
│   ├─ js/
│   │   └─ main.js
│   └─ img/
│       └─ logo.svg   (placeholder for IIIT Hyderabad logo)
├─ data/
│   └─ config.json   (dates, fees, curriculum, contacts)
└─ README.md
```

The site follows the design specifications provided: minimal academic style, responsive layout, smooth scrolling, accordions for curriculum & FAQ, and a sticky navigation bar.

> **Note**: All frequently‑changing values (dates, fees, URLs) are stored in `data/config.json` as placeholders (`[PLACEHOLDER]`). Replace them with official values before deployment.
